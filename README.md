# OneFitVIVES — Rookstopchallenge

Een progressieve webapplicatie (PWA) die gebruikers begeleidt tijdens een rookstopchallenge van 84 dagen.

## Inhoud

De app biedt dag per dag:
- een motivatiequote
- wetenschappelijk onderbouwde informatie over de voordelen van stoppen met roken
- inzicht in de financiële besparing
- een ademhalingsoefening (4-7-8 methode)
- een buddy-systeem voor extra ondersteuning

## Bestanden

| Bestand | Omschrijving |
|---|---|
| `index.html` | Volledige applicatie (één bestand, geen externe afhankelijkheden) |
| `manifest.json` | PWA-manifest voor installatie op toestel |
| `sw.js` | Service worker voor offline werking |
| `icon-192.png` | App-icoon (192×192 px) |
| `icon-512.png` | App-icoon (512×512 px) |

## Publiceren via GitHub Pages

1. Maak een nieuw repository aan op [github.com](https://github.com).
2. Upload alle bestanden uit deze map naar de root van het repository.
3. Ga naar **Settings → Pages**.
4. Kies bij *Source*: **Deploy from a branch → main → / (root)**.
5. Sla op. Na enkele seconden is de app beschikbaar op `https://<gebruikersnaam>.github.io/<repository-naam>/`.
